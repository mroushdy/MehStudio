# MEH Studio Build 655 handoff

Build 655 is the current release source identity. It supersedes Build 654.
Earlier numbered builds, screenshots, hashes, and browser witnesses are
historical regression evidence only.

## Launch

From `application/v5`:

```bash
node serve.js 8520
```

Open:

```text
http://127.0.0.1:8520/meh5.html?build=655&reset=1&view=full&rev=release-final
```

## Delivered three-way surface

- The calculated T3 family opens as a guided, slider-driven design and renders
  a solved LF/MF/HF assembly without requiring JSON.
- Family selection also exposes documented CX3 and H3 references without
  inventing missing dimensions or treating photographs as manufacturing data.
- Driver selectors are band-specific and show compatibility status.
- Full-assembly, no-driver mount, lumen, and section-cutaway views are
  deterministic and camera-fitted.
- The calculated T3 owns full-face positive mounting hosts, adapters, four
  canonical wall-entry flow paths, and closed positive/negative solid operands.
- Build reset clears both the shared saved state and the schema-2 three-way
  state, after build identity has been accepted.

## Capability boundary

Build 655 provides calculated three-way analysis, guided controls, closed
operand construction, and validated visual inspection. It does **not** bundle
an admitted exact Boolean provider, deep manufacturing audit, or authorized
three-way STL. Exact mesh and STL controls therefore remain locked. This is an
intentional safety boundary, not a hidden success claim.

## Integrity

`BUILD655-FILES.sha256` verifies every packaged regular file except itself.
The sibling `MEH-Studio-build655-private.zip.sha256` binds the complete ZIP,
including that source manifest. Installed dependencies, QA artifacts,
temporary files, credentials, browser state, local pins, and Git metadata are
excluded.

## Truth boundary

- Analysis success is not an exact mesh.
- Closed constructive operands are not a completed Boolean result.
- An exact closed manifold is not fabrication admission by itself.
- A fabrication authorization is not physical acoustic, structural, thermal,
  sealing, material, or safety validation.
